StreamTrack TV shows how a television is used. A small Android TV app records screen-on time, how long each app is in the foreground and how often each kind of remote key is pressed. It sends hourly totals to a dashboard that runs in your own Vercel and Supabase accounts. Nobody else holds the data.

The current schema version of the sync package is {{version}}. The [changelog](/changelog) lists what each release changed.

## Why self-hosted

A TV sees a lot about a household: what is watched, when, and for how long. A hosted service would have to store that for everyone. This project does not run such a service. You deploy the dashboard and the database yourself, and the TV app talks only to the address you pair it with.

The code is open, so you can read what the app collects and what the server stores. The [privacy and security](/privacy-and-security) page lists every field.

## Why privacy-first

The app collects counts and durations and nothing else. It never records which buttons were pressed beyond a class such as `dpad` or `media`. It never records text, window content, screenshots, contacts or what was watched inside an app. The TV also has a screen that shows the exact payload before it leaves the device.

## What you get

- Screen time per day and per hour.
- Foreground time per app, grouped into categories you can edit.
- Remote keypress counts by class, plus an hour-by-weekday heatmap.
- Several TVs and household profiles in one dashboard.
- Daily and weekly goals, a weekly email digest and read-only share links.
- Export, retention settings and full deletion.
- A demo mode with seeded data, so you can look around without a TV.
