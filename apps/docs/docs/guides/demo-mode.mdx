---
title: Demo mode
description: Explore the dashboard with seeded data and no TV.
---

The public demo at [streamtrack-tv.vercel.app/demo](https://streamtrack-tv.vercel.app/demo) shows the dashboard with generated data. It needs no account, and you cannot change anything in it.

Your own instance serves `/demo` too. Setting `DEMO_ONLY=1` turns the whole site into a demo, as described in [self-hosting](/guides/self-hosting#demo-only-deployment).

Debug builds of the TV app have a separate demo feature, **Settings, Load demo week**, which fills the local database with a generated week. Release builds do not contain it.
